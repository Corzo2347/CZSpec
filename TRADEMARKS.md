# CZSpec name, logo, and project identity

The source code of CZSpec is licensed under **GNU GPL-3.0-only**. That software license does not grant permission to misrepresent the origin of the software or to imply official endorsement by the CZSpec project.

## Official project identity

The following identify the official CZSpec project maintained by Oscar Corzo:

- the name **CZSpec** when used to identify the official project or an official distribution;
- the official CZSpec logo;
- official visual assets and branding presented as belonging to the CZSpec project;
- terms such as **Official CZSpec**, **CZSpec Official**, **CZSpec Certified**, or similar wording that implies authorization, certification, or endorsement.

This policy is separate from the GPL license covering the source code.

## Permitted descriptive use

You may truthfully refer to CZSpec when:

- stating that software is based on or compatible with CZSpec;
- writing papers, documentation, reviews, tutorials, courses, or educational material about CZSpec;
- identifying a fork or modified version as being derived from CZSpec;
- linking to the official repository.

Examples:

- “A community module for CZSpec”
- “A modified version based on CZSpec”
- “Course on molecular spectroscopy using CZSpec”

## Uses that require prior permission

Prior written permission from the project maintainer is required to:

- present a third-party product, service, course, workshop, certification, or distribution as **official**, **certified**, **endorsed**, or **authorized by CZSpec**;
- use the official CZSpec logo in a way that suggests sponsorship or affiliation;
- use CZSpec branding in a confusing way that could make a modified or unrelated distribution appear to be the official project.

A third party may teach or discuss CZSpec without permission, but must not imply that its activity is an official CZSpec activity unless authorization has been granted.

## Modified distributions

Modified versions should clearly identify that they have been changed and should not create confusion with the official release.

A recommended notice is:

> Based on CZSpec, originally created by Oscar Corzo. This is a modified distribution and is not an official CZSpec release.
